# User Journey Guide

This guide summarises the AHP Study Leave and CPD request journey shown in the [redacted visual walkthrough](../screenshots/README.md). It omits internal links and operational records.

## Applicant

1. Read and accept the learning terms in the request form.
2. Enter course details, dates, funding source, requested hours, and supporting evidence.
3. Submit the request and retain the confirmation.
4. Read the updates sent after line manager review, panel review, and any procurement steps.
5. After the activity, complete the attendance confirmation when requested.

## Line manager

1. Open the review form linked to the request.
2. Consider the request and any staffing cost implications.
3. Record the decision in the form. The outcome is added to the application record and the applicant receives an update.

## Panel and administrators

1. Review requests awaiting a panel decision in the model-driven app.
2. Record the panel outcome.
3. For an approved request, track the relevant purchase order, card payment, or no-payment route.
4. Update the request as the administrative steps are completed.

## Reporting

Authorised users can monitor requests and statuses in the Power Apps dashboard. The Power BI report provides views of application activity, funding, hours, and outcomes.
